AdMob API OAuth プライバシーポリシー

本ポリシーは、kaeru07 が自身の AdMob アカウントの情報を取得・集計するために利用する OAuth 連携（以下「本ツール」）における Google ユーザーデータの取り扱いについて説明します。

1. アクセスする Google ユーザーデータ

本ツールは Google AdMob API の読み取り専用スコープ https://www.googleapis.com/auth/admob.readonly を利用し、認可した AdMob アカウントのアカウント情報、アプリ・広告ユニット情報、広告レポート等にアクセスします。

2. 利用目的

取得したデータは、開発者本人の AdMob 運用状況、広告収益、広告配信状況等の確認・集計・分析、および個人開発アプリの改善判断のためにのみ利用します。

3. 保存

OAuth の認証情報は、自動処理に必要な範囲で非公開のシークレットとして管理します。取得した AdMob データは、運用状況の確認・分析・履歴管理に必要な範囲で保存される場合があります。認証情報や取得データを公開ページに掲載することはありません。

4. 共有

Google ユーザーデータを販売したり、広告目的で第三者へ提供したりしません。本ツールの実行・保存に必要なクラウドサービス事業者が、サービス提供上必要な範囲でデータを処理する場合があります。

5. データの保持と削除

認証情報は本ツールの利用に必要な期間のみ保持します。OAuth アクセスは Google アカウント側で取り消すことができ、不要になった認証情報は削除します。取得データについても、運用・分析上不要になった場合は削除します。

6. Google API Services User Data Policy

Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use requirements を含む）に従います。

7. App Store アプリ利用者について

App Store で公開しているアプリの一般利用者に、本ツールの OAuth 認可を求めることはありません。本ツールは開発者本人の AdMob 管理用途を想定しています。

8. ポリシーの変更

本ポリシーは、利用するデータや処理方法に変更がある場合に更新します。変更後の内容は本ページへの掲載時から適用されます。

9. お問い合わせ

本ポリシーに関する問い合わせは、開発者の GitHub プロフィールからご確認ください。
