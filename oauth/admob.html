AdMob API Data Access

このページは、kaeru07 が自身の AdMob アカウントの情報を自動取得・集計するために利用している OAuth 連携について説明するものです。

機能

Google AdMob API を利用し、開発者本人の AdMob アカウントに関するアカウント情報、アプリ・広告ユニット情報、広告レポート等の読み取り専用データを取得し、収益・広告配信状況の把握や個人開発アプリの改善判断に利用します。

Google ユーザーデータを利用する目的

OAuth 認可では、AdMob データを読み取るための admob.readonly スコープのみを利用します。取得した情報は、開発者本人の AdMob 運用状況の確認・集計・分析のためにのみ利用します。

対象ユーザー

この OAuth 連携は開発者本人の管理用途を想定しています。App Store で公開しているアプリの利用者が Google アカウントでログインしたり、この OAuth 連携を許可したりする必要はありません。

プライバシー

Google ユーザーデータのアクセス、利用、保存、共有に関する詳細は、AdMob API OAuth プライバシーポリシーをご確認ください。
